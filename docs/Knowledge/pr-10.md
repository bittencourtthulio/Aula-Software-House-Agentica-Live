# Como criar quadros e reconhecer limites do contrato de automação

## Quando consultar
Consulte para responder como criar quadros ou quando uma sessão não conhece o contrato de resultado do controlador.

## Contexto e causa
A issue era dúvida de uso. O N1 consultou PRODUTO.md. Naquela sessão houve bloqueio para produzir JSON final porque o controlador acessível não especificava outcomes.

## Solução e decisão
Orientação registrada: na página inicial clicar em “Abrir meus quadros”; na lateral escolher “Criar quadro” e informar título. Dentro do quadro, “Adicionar lista” cria as etapas. Se um contrato técnico estiver ausente, registrar a lacuna em vez de inventar valores.

## Evidências e validação
A PR foi integrada, mas a API de arquivos retorna lista vazia: o conhecimento está na descrição e nos marcos, não em uma mudança de código. A issue #9 contém o retorno do N1 e o bloqueio de formalização. Fonte funcional: docs/automacao-atendimento/PRODUTO.md.

Fonte: [PR #10](https://github.com/bittencourtthulio/Aula-Software-House-Agentica-Live/pull/10).

## Limites e prevenção
O bloqueio do controlador é histórico: releia automacao/controlador.mjs e o contrato atual antes de afirmar que persiste. Merge de PR sem diff não implementa uma funcionalidade nem comprova que o JSON foi gravado.
